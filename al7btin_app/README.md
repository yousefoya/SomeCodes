## 🌟 الهوية البصرية والتصميم (Brand Identity)

* **الاسم**: بتنحل / AL7BTIN
* **الثيم والتصميم**: أسود ملكي مع لمسات ذهبية متدرجة فاخرة (**Luxury Black & Gold Theme**).
* **اللغة والاتجاه**: عربية بالأساس (**Arabic-First**) مع دعم كامل للاتجاه من اليمين لليسار (**RTL**) وتجهيز مرن للغة الإنجليزية (**LTR**).

│   │   └── app_strings.dart      # النصوص والمسميات

## 🧭 خريطة التنقل المبدئية (Navigation Map)

1. **`/` (`RouteNames.splash`)**: شاشة البداية المتحركة.
2. **`/login` (`RouteNames.login`)**: تسجيل الدخول برقم الهاتف و OTP.
3. **شريط التنقل السفلي (ShellRoute)**:
   - **`/home`**: الصفحة الرئيسية واستعراض الخدمات.
   - **`/categories`**: الأقسام والفئات (مبنية لدعم الإضافة الديناميكية من الـ Admin).
   - **`/orders`**: سجل الطلبات ومتابعة الحالات.
   - **`/profile`**: حساب المستخدم، رصيد المحفظة، نقاط الولاء، وكود الدعوة.
4. **مسارات الوحدات المستقبلية المجهزة**:
   - **`/service/:id`**: تفاصيل الخدمة / المنتج.
   - **`/checkout`**: إتمام الطلب والدفع.
   - **`/orders/track/:id`**: تتبع الطلب والخريطة المباشرة.
   - **`/supplier`**: بوابة المزودين.
   - **`/technician`**: بوابة الفنيين ومطابقة الطلبات.
   - **`/admin`**: بوابة لوحة الإدارة.

## ⚡ قواعد العمل الأساسية والتجريد (Core Principles)

1. **المرونة والديناميكية**: عدم تضمين أي خدمة (مثل الغاز، الماء، السباكة) بشكل ثابت أو كودي مقيد في النواة؛ جميع الخدمات تُعامل ككيانات ديناميكية قابلة للإضافة والتعديل من لوحة الإدارة لاحقاً.
2. **الحسابات المالية**: الحسابات المالية (السعر، التوصيل، الخصم، الكشفية، أجور اليد) يتم التحقق منها واعتمادها نهائياً من الخادم Backend.
3. **تجريد الخدمات الخارجية**: بوابات الدفع (Payment Gateways) وخرائط جوجل (Google Maps) مجردة بالكامل خلف Interfaces تمنع الاعتماد المباشر في طبقة العرض.

## 🚀 كيفية تشغيل المشروع (Running the Project)

1. تأكد من تثبيت **Flutter SDK** وإضافته إلى متغيرات البيئة (PATH).
2. افتح مجلد المشروع:
   ```bash
   cd al7btin_app
   ```
3. ثبّت الحزم والاعتماديات:
   ```bash
   flutter pub get
   ```
4. شغّل الفحص الثابت للتأكد من جودة الكود:
   ```bash
   flutter analyze
   ```
5. شغّل الاختبارات:
   ```bash
   flutter test
   ```
6. شغّل التطبيق على الجهاز أو المحاكي:
   ```bash
   flutter run
   ```
